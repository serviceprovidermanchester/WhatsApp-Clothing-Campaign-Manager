# Contributing Guidelines

Thank you for contributing to the SPM WhatsApp Campaign Engine, an open-source initiative by **SPManchester Private Limited** (https://www.spmanchester.com).

## How to Submit Changes
1. Fork this repository and create your feature branch (`feature/new-feature`).
2. Adhere to PSR-12 code style guidelines and modern PHP 8.1+ practices.
3. Ensure no private keys, webhook tokens, or credentials are committed.
4. Open a Pull Request detailing the purpose, changes made, and verification steps.
