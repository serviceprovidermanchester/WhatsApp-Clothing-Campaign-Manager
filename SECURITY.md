# Security Policy - SPM WhatsApp Campaign Engine

Engineered and maintained by **SPManchester Private Limited** (https://www.spmanchester.com).

## Reporting Security Issues

We take data protection and API security seriously. If you encounter any potential security vulnerability:

1. Send an email directly to **info@spmanchester.com**.
2. Mention `[Security Vulnerability]` and the project name in the subject line.
3. Provide details to reproduce the behavior and any proposed remediation.

Our team will investigate your disclosure and address verified findings promptly. Please do not open public issues for sensitive security vulnerabilities.
